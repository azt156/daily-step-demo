每天 3 分鐘
把讀過的書，變成你的寫作資料庫

不用讀完整本書。一個章節、一個觀點、一個故事，就能開始。

兩種玩法，自由選：
✅ 每日打卡（3 分鐘小任務）
翻開今天讀的書，留下書名、作者、一個觀點關鍵詞，再寫一個書中故事或一句金句，就算完成。一天一次，只存在自己的學習歷程；漏打的日子 7 天內可以補。打完卡還能把金句做成卡片，分享到 IG／FB。
🏁 闖關（寫一篇完整心得）
當天想法比較多？走完四頁（四寶 → 我的觀點與故事 → 別人的故事 → 讀後行動）組成一篇心得，繳交給老師批改（收在「學習成果 → 文章管理」）。打卡寫到一半突然有感覺，也可以按「順手去闖關」，系統會把四寶直接帶過去。
🌱 為什麼要每天打卡？
・用原子習慣的方式，把閱讀寫作的門檻降到最低，每天立即得到成就感
・每次打卡都是一則帶日期的小筆記——作文要引用論據，隨時從這裡調
・一天一則，一年就是 365 則：看得見的累積痕跡，也是高中學習歷程「持續閱讀」的證明
・分享金句卡，再得到一次社群的成就感，找到一起讀書的同路人

關卡地圖

依序闖關、隨時暫存；也可以一口氣寫完。完成四頁後，來這裡組裝文章。

第一頁｜閱讀四寶

不用讀完整本書。挑一個你有感覺的章節，把四樣寶物存進你的存摺。

翻到你喜歡的章節，用一個詞說出它的觀點。例：馴養、勇氣、選擇。

支撐這個觀點的故事，用自己的話說：一句話 ≤30 字，或一小段 ≤120 字。超過就很像灌水囉。

0 字（建議 120 字內）

習慣手寫？拍一張照片上傳也可以。

第二頁｜我的觀點與故事

從你的關鍵詞出發：你同意書中的觀點嗎？然後，講一個你自己的故事。

你同意「這個觀點」嗎？為什麼？一句話說清楚。

連結你自己的生命經驗，至少 50 字。先寫再說，流水帳也沒關係。

0 字（至少 50 字）

第三頁｜別人的故事（選寫挑戰）

有誰也是這樣的人？從一個角度換位思考，分數會更高；想不出來，寫「我學到了什麼」也可以過關。
想不出來也沒關係

第四頁｜讀後行動

文字不能只停在紙上。讀了這本書，你可以做的一個行動是什麼？寫下你夢想的最高規格版本——沒有 100 分，也有 80 分。

具體、這週就做得到的事。例：每天放下手機十分鐘，認真聽家人說話。
